## Deploying to GitHub Pages
1. Create a new public repository on [GitHub](https://github.com/new) named `SairajPulaparthi1.github.io` (or `portfolio`).
2. Add the remote and push the `main` branch:
   ```bash
   git remote add origin https://github.com/SairajPulaparthi1/SairajPulaparthi1.github.io.git
   git push -u origin main
   ```
3. In your repository on GitHub, go to **Settings → Pages**, and under **Build and deployment**, set **Source** to **Deploy from a branch** (`main` / `/ (root)`).
